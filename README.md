# pr-manager-release

Homebrew cask and release binaries for [pr-manager](https://github.com/yanislavm/pr-manager).

## Install

This repo isn't named `homebrew-pr-manager-release`, so `brew tap` needs the
full repo URL rather than the `owner/name` shorthand:

```sh
brew tap yanislavm/pr-manager-release https://github.com/yanislavm/pr-manager-release
brew install --cask pr-manager
```

## Upgrade

```sh
brew upgrade --cask pr-manager
```
